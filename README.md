# 📊 Sales & Performance Dashboard

An interactive and dynamic dashboard project built to analyze performance metrics, track sales productivity, and visualize key performance indicators (KPIs) effectively.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data organization, pivot tables, and initial layout design.
* **Power BI:** Interactive data visualization, KPI metrics, and reporting.

---

## 📂 Project Overview
This project focuses on translating raw tracking data into clear, actionable visual insights. It highlights personal productivity trends, goal achievements, and performance breakdowns through structured charts.
